## 📌 Project Overview

This project is a dynamic web application built using Python and Flask.
It demonstrates full-stack development by integrating backend logic with HTML, CSS, and JavaScript.

The application functions as a personal portfolio website that showcases:

* Projects
* Skills
* About information
* A contact form with validation

---

## 🎯 Project Objectives

* Build a dynamic Flask web application
* Implement multiple routes and templates
* Use Jinja templating (loops, conditions, dynamic content)
* Handle GET and POST requests
* Implement CRUD functionality
* Apply modern CSS styling
* Add JavaScript interactivity
* Deploy the application using Render

## ▶️ Running the Project Locally

1. Clone the repository:

```
git clone https://github.com/HlengiweNcube/flask-web-app
```

2. Navigate into the folder:

```
cd flask-web-app
```

3. Create a virtual environment:

```
python -m venv venv
```

4. Activate it:

* Windows:

```
venv\Scripts\activate
```

* Mac/Linux:

```
source venv/bin/activate
```

5. Install dependencies:

```
pip install -r requirements.txt
```

6. Run the app:

```
python app.py
```

7. Open in browser:

```
http://127.0.0.1:5000/
```

## 🚀 Deployment on Render

Steps followed:

1. Created a GitHub repository
2. Pushed project to GitHub
3. Logged into Render
4. Created a new Web Service
5. Connected the GitHub repository
6. Configured:

   * Build command: `pip install -r requirements.txt`
   * Start command: `gunicorn app:app`
7. Enabled auto-deploy from `main` branch
8. Render builds and deploys automatically
