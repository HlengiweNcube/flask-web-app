## 🔗 Repository and Deployment Connection

This project is hosted on GitHub and deployed using Render.

The Render web service is directly connected to the GitHub repository:
https://github.com/HlengiweNcube/flask-web-app

Auto-deployment is enabled using the **“On Commit”** setting.
This means that every push to the `main` branch automatically triggers a new build and deployment on Render.

The difference in naming (e.g. `flask-web-app-hlengiwe`) is automatically generated by Render to ensure a unique service URL.

## 📌 Project Overview

This project is a dynamic web application built using Python and Flask.
It demonstrates full-stack development by integrating backend logic with HTML, CSS, and JavaScript.

The application functions as a personal portfolio website that showcases:

* Projects
* Skills
* About information
* A contact form with validation

---

## 🎯 Project Objectives

* Build a dynamic Flask web application
* Implement multiple routes and templates
* Use Jinja templating (loops, conditions, dynamic content)
* Handle GET and POST requests
* Implement CRUD functionality
* Apply modern CSS styling
* Add JavaScript interactivity
* Deploy the application using Render

---

## ⚙️ Flask Features Implemented

### Routing

* Multiple routes for different pages
* Dynamic routes using parameters:

  * `/edit_project/<int:project_id>`
  * `/delete_project/<int:project_id>`

### Jinja Templates

* Loops (`for`)
* Conditions (`if`)
* Dynamic data rendering
* `url_for()` used for navigation

### Data Structures

* Lists and dictionaries for projects and skills
* Python functions for data lookup

## ▶️ Running the Project Locally

1. Clone the repository:

```
git clone https://github.com/HlengiweNcube/flask-web-app
```

2. Navigate into the folder:

```
cd flask-web-app
```

3. Create virtual environment:

```
python -m venv venv
```

4. Activate:

* Windows:

```
venv\Scripts\activate
```

* Mac/Linux:

```
source venv/bin/activate
```

5. Install dependencies:

```
pip install -r requirements.txt
```

6. Run:

```
python app.py
```

7. Open:

```
http://127.0.0.1:5000/
```
